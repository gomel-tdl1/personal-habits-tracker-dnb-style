# Drop

Личный трекер привычек в стиле drum & bass: конструктор трекеров, конструктор дашборда и звук на каждое действие. Next.js 16 + Supabase, деплой на Vercel.

## Локально за минуту

```bash
pnpm install
pnpm dev
```

Если переменных Supabase нет, приложение в dev-режиме запускается в **демо-режиме**: данные лежат в `localStorage` браузера, вход не нужен, есть тестовые данные за 110 дней.

## Supabase

1. Создай проект на [supabase.com](https://supabase.com).
2. **SQL Editor** → вставь содержимое [supabase/migrations/001_init.sql](supabase/migrations/001_init.sql) → Run. Это создаст таблицы и RLS: доступ к строкам есть только у владельца.
3. **Authentication → Sign In / Providers → Email**: выключи **Allow new users to sign up**. Регистрация извне будет невозможна.
4. **Authentication → Users → Add user → Create new user**: email и пароль, отметь **Auto Confirm User**.
5. **Project Settings → API Keys**: скопируй Project URL и publishable key (`sb_publishable_…`; старый `anon` ключ тоже подойдёт).

Создай `.env.local` по образцу [.env.example](.env.example):

```bash
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

Публичный ключ виден в браузере, это нормально: без входа RLS не отдаст ни одной строки.

## Треки для дропа

Когда закрыт весь день, играет дроп настоящего трека из твоей библиотеки. Пока треков нет или трек не успел загрузиться, играет синтезированный дроп.

1. **SQL Editor** → выполни [supabase/migrations/002_tracks.sql](supabase/migrations/002_tracks.sql), затем [003_track_scenes.sql](supabase/migrations/003_track_scenes.sql). Появятся приватный бакет `tracks` и таблица `drop_tracks` со сценами.
2. **Storage → tracks** → перетащи файлы (MP3, M4A или WAV, до 20 МБ). Лучше фрагменты секунд на 40 вокруг дропа: быстрее грузятся на телефоне.
3. **Table Editor → drop_tracks** → по строке на файл:
   - `file` — имя файла в бакете, например `rock-it.mp3`;
   - `artist`, `title` — подпись на заставке;
   - `drop_at` — секунда первого удара дропа, например `9.65`. Точность ±0.08 с достаточно: приложение само подстраивает сетку под реальные удары;
   - `bpm` — темп, если известен (обычно 174); пусто — определяется сам;
   - `style` — анимация: `punch` (пробитая стена), `circuit` (плата), `ripple` (волны на воде), `kaleido` (калейдоскоп), `siren` (сирена), `speaker` (динамик); пусто — случайная из них. Старые `rave`, `bounce`, `euphoria`, `anthem` принадлежат синтезированным дропам;
   - `enabled` — снять галочку, чтобы временно выключить трек.

Готовые фрагменты (WAV без потерь) и SQL для них лежат в `tracks/drops/`: загрузи `.wav` в бакет и выполни `drop_tracks.sql`. Папка `tracks/` исключена из git, треки не попадут в репозиторий и на Vercel.

Примерно в одном случае из десяти вместо трека играет синтезированный дроп, для разнообразия. Все анимации можно посмотреть без звука на странице `/dev/drops` (только в режиме разработки).

Приложение заранее скачивает случайный трек, когда до закрытия дня остаётся одна-две привычки, и кэширует файл в браузере. Кики и снейры для пульсации и стробоскопа находятся анализом самого трека.

## Vercel

1. Залей репозиторий на GitHub и импортируй его в Vercel (фреймворк определится сам).
2. В **Settings → Environment Variables** добавь те же две переменные.
3. Deploy.

На телефоне открой сайт и выбери «На экран „Домой“»: приложение запустится без адресной строки.

## Как устроено

- `src/proxy.ts` обновляет сессию Supabase и отправляет на `/login` без входа. Это вся серверная часть.
- `src/lib/habits.ts` — логика «день засчитан», серии, процент выполнения (тесты рядом).
- `src/lib/repo/` — доступ к данным: Supabase или демо-режим.
- `src/lib/sound/synth.ts` и `drops.ts` — синтез на Web Audio: фа минор, 174 BPM, четыре стиля дропа.
- `src/lib/sound/tracks.ts` и `beats.ts` — загрузка треков из Storage и поиск сетки кика и снейра.
- `src/components/today/useCommit.ts` — какой звук и эффект играет на каждое действие.

| Действие | Звук | Визуал |
| --- | --- | --- |
| Галочка | аккорд + снейр | ударная волна |
| +1 к счётчику | нота выше по гамме | LED-сегмент |
| Число или время | риз-бас | — |
| Цель достигнута | райзер → саб-дроп | двойная волна, вспышка карточки |
| Весь день закрыт | дроп трека из библиотеки или синтезированный (Rave, Bounce, Euphoria, Anthem) | лазеры, LED-стена, лучи или эквалайзер; пульсация в такт |
| Отмена | tape stop | — |

Звук выключается кнопкой с динамиком. На iPhone он играет и при беззвучном режиме (Safari 16.4+).
